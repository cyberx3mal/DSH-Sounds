# Changelog

## 1.1.0 — 2026-11-12

### Added

- **Причина завершения turn.** Хостовая проекция `lastTurnEnd` (durable `turn/end.reason`) отличает успешное завершение от остановки пользователем, ошибки, лимита токенов, заблокированной цели и аварийного закрытия turn. «Стоп» больше не звучит как «Работа завершена», а `error`/`max-tokens` дают звук ошибки. Без проекции (старая версия DSH) используется прежнее поведение по переходу `running`.
- **Звук для упавших фоновых задач.** Ростер `ctx.jobs` подписывается на сессии, которые работают или работали последние 5 минут (до 24 сессий); переход задачи в `failed` играет звук ошибки, а задачи, уже упавшие к моменту подписки, считаются базой и не сигналят.
- **Автоповтор сигнала.** Новый блок настроек: повторять звук, пока проект не открыт, или заданное число раз (1–30) с интервалом 5–300 секунд. Открытие проекта в основной области (или закрытие ожидающего approval/question) считается прочтением; если проект уже открыт, сигнал играет один раз; сигналы без проекта замолкают при возврате видимости вкладки; повтор «до открытия» ограничен 10 минутами.
- **Режим «только когда вкладка в фоне»** — не играть, пока окно DSH активно.
- **Настройки в профиле DSH.** Хостовая половина объявляет volatile `Config`, клиент читает и пишет его через `ctx.configForms`; настройки общие для всех браузеров профиля. При первом запуске поля, которые профиль ещё не переопределял, переносятся из браузера и записываются в профиль; явно сохранённые значения профиля главнее. При недоступности Host-настроек используется `localStorage`.
- **Иконка раздела настроек** (`settings.section.icon`) и `aria-label` у переключателей.
- **Тесты и CI.** `node --test` для host и client (дефолты, миграция, baseline, причины turn/end, фоновые задачи, автоповтор, видимость, синхронизация настроек, рендер страницы) и GitHub Actions.
- **Документация на двух языках.** `README.md` (русский) и `README.en.md` (English) со ссылкой-переключателем в начале; раздел «Благодарности» с честной формулировкой о происхождении ранней версии.

### Changed

- Дефолтные звуки: «Работа завершена» → **Перезвон**, «Нужно разрешение или ответ» → **Дерево**, «Ошибка» → **Сирена**. Сохранённые настройки, в которых все три звука оставались старыми дефолтами, один раз обновляются; изменённые вручную значения и переопределения по проектам не трогаются.
- Подпись «Общий» в селектах проектов показывает, какой звук наследуется.
- Оверрайды удалённых проектов удаляются при открытии страницы настроек.
- Зависимость `@deepseek-ai/schemastery` для хостовой половины.

### Fixed

- Ложный звук ошибки при загрузке страницы, если цель уже заблокирована или контекст уже ≥ 90%: первая порция проекций теперь считается базой.
- Утечка регистрации наблюдателя квоты при перезагрузке плагина: возвращаемый disposer теперь реально вызывается.
- Гонка между статусом сессии и проекцией `lastTurnEnd`: завершение turn дожидается свежей проекции (один короткий повтор), затем откатывается к прежнему поведению.
